# Third-party components

uHighlight bundles the following third-party files. Each keeps its own
license; uHighlight's own code is under the [GNU GPL v3.0](LICENSE).

| Component | Version | License | Location |
| --- | --- | --- | --- |
| [Font Awesome](https://fontawesome.com/v4/) icons, by Dave Gandy | 4.7.0 | [SIL OFL 1.1](https://openfontlicense.org/) | `img/icons.svg` (19 icons, as SVG symbols), notice in `img/LICENSE-fontawesome.txt` |
| [Roboto Condensed](https://fonts.google.com/specimen/Roboto+Condensed) font, by Google (Regular and Light) | 1.100141 | [Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0) | `fonts/RobotoCondensed-Regular.ttf`, `fonts/RobotoCondensed-Light.ttf`, license in `fonts/LICENSE.txt` |

The icons are drawn from the Font Awesome 4.7.0 font's glyphs and are used
unchanged. The font files are the original ones; the extension's pages use
the copy installed on the computer when there is one.
